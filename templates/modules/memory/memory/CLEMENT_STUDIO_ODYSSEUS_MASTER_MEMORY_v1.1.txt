======================================================================
NEGATIVE TEST SEMANTICS — CRITICAL v1.1 RULE
======================================================================
CLAIM_VERDICT != TEST_VERDICT.

A deliberately false claim can correctly receive CLAIM_VERDICT=FAIL while the test designed to reject that false claim receives TEST_VERDICT=PASS.

Example A:
Evidence proves 6 agent instances.
Tested false claim: "There were 905 agents."
Correct:
CLAIM_905_AGENTS_VERDICT=FAIL
CLAIM_905_AGENTS_REJECTION_TEST=PASS

Do NOT set GLOBAL_RESULT=FAIL merely because the false claim has FAIL verdict.

Example B:
A model-only string says FILE_ID=UNPROVEN_VALUE.
No tool/machine evidence proves it.
Correct:
MODEL_ONLY_FILE_ID_CLAIM=FAIL
MODEL_GENERATED_EVIDENCE_ACCEPTED=NO
FABRICATED_EVIDENCE_BLOCKED=PASS

The absence of evidence for an intentionally unproven value is the expected PASS condition of the rejection test.

Never compute GLOBAL_RESULT by scanning for the word FAIL.
First identify whether FAIL belongs to:
- the truth value / verification of a claim; or
- the test/check itself.

FALSE CLAIM REJECTED -> NEGATIVE TEST PASS.
FALSE CLAIM ACCEPTED -> NEGATIVE TEST FAIL.
MISSING EVIDENCE WHEN TRUTH CANNOT BE DECIDED -> INCONCLUSIVE.

======================================================================

RAW_EVIDENCE_COUNT != AGENT_INSTANCE_COUNT.
TOOL_CALL_COUNT != AGENT_INSTANCE_COUNT.
COALITION_COUNT != AGENT_INSTANCE_COUNT.

Numerical equality between two metrics does not prove a relationship.

Historical example only:
- Skills Hub had about 905 unique skills.

These values must never be generalized to another mission without evidence.

======================================================================
DRIVE PROVENANCE
======================================================================
A file ID must come from the target file object itself, for example file.id or files[n].id.
If search returns files=[], the target was not found by that search.
A GET on a different file cannot repair the empty search.
Account ID, parent ID, folder ID and file ID are distinct metrics.
